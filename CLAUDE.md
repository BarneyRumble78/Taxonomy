# Taxonomy: guide for Claude Code

Taxonomy is a standard classification of human knowledge: 25 fields, each a Minto pyramid with four faces (Objects, Methods, Warrants, Bridges), one shared rule set (Standard v2, R1–R12) and 984 stable IDs. Owner: Chris Townsend. Read `standard/STANDARD_V2.md` before changing any pyramid.

## Layout
- `standard/STANDARD_V2.md`: the rules. Do not loosen them without the owner's say-so.
- `pyramids/XX.md`: one file per field (MA, PH, CH, BI, EA, MD, EN, CS, MS, EC, BU, ST, PO, LA, PL, HI, LN, AR, RE, ED, DE, AG, EV, IS, IK) plus `ANZSRC45.md`. Sections 1–13 in fixed order.
- `registry/`: generated by `scripts/build_registry.py` from section 12 of each pyramid. Never edit by hand.
- `engine/`: `taxonomy_engine.py` (rule-based classifier and whole-view) and `lexicon.json` (cue words per field, cell, warrant, method).
- `site/`: `template.html` (tabbed website, single file), `site_data.json` (field names, key-line cells, pilot claims), `dist/` (build output, published as a claude.ai artifact).
- `pilot/`: 50-claim placement pilot (AI coders), protocol, codebook.
- `docs/`: combined v2.2 file, Māori-led review pack, APSA crosswalk, related work, ABS ANZSRC 2020 source file.
- `tests/`: pytest for the engine.

## Commands
```
python3 scripts/check.py            # R1/R2/R7 checks: dangling IDs, sub-cell counts, key-line agreement
python3 scripts/build_registry.py   # regenerate registry/
python3 scripts/build_site.py       # regenerate site/dist/index.html
python3 -m pytest -q tests          # engine tests
python3 engine/taxonomy_engine.py "a sentence"      # classify
python3 engine/taxonomy_engine.py --view "subject"  # 25-field view
```
Run check, registry, tests and site build after any change to a pyramid, the lexicon or the template.

## Rules that must hold
- One sentence, one home (R1). Owner = the field whose warrant establishes the claim. Others cite "uses XX.O.An".
- IDs are stable (R12). Never renumber; retire an ID (mark RETIRED, point to the new home) instead of reusing it. Example: MS.O.A1.5.5 retired to ED.
- Key-line members appear word for word in sections 2, 3 and 11 (R7). 2–5 members. No "Other".
- Every named theorem carries its hypotheses in the sentence (R5).
- Mathematics (MA) is the apex and owner of every theorem. Do not restructure MA's five cells or its 63/63 MSC placement.
- W13 (tradition-internal authority) never licenses a measurement, date, legal duty or word meaning.
- IK and every Indigenous placement stay provisional until Māori-led review (`docs/MAORI_REVIEW_PACK.md`). Do not mark them final.
- Mark unchecked facts `(UNVERIFIED)`. Do not invent citations. Record sources checked with the date.
- Plain academic register, sentences under 25 words, no self-sealing rhetoric (R10).

## Website conventions (site/template.html)
- Look: circa-2010 government / standards-body site. Fixed 960px sheet, blue banner, big Menu button top left, tab bar, left sidebar boxes, breadcrumb, grey footer. Single light theme. Georgia headings, Arial body.
- Name is "Taxonomy" (no "The", no "Pyramids of Knowledge").
- Leads with mathematics. Sells it as a new tool for the age of AI. Plain human headings.
- Do not use "we publish our own failures" as a selling point. No invented testimonials, stats or endorsements.
- Copy follows Bob Bly's formulas: benefit and USP in headline and first sentences, 4 U's, eight persuasion elements, technical-audience tone.
- The page runs in a sandbox: no external fetches, only allowlisted CDNs, no Python in the browser. The JS engine in the template must stay a faithful port of `engine/taxonomy_engine.py`.
- Deep analysis uses the claude.ai `sample` capability (declared at publish: `{"sample": {}}`).
