TaxonomyAPI for placing claims and mapping subjects across 25 fields of knowledge

Ask what kind of evidence settles a claim.

Send a sentence or a subject. Taxonomy returns the field that owns it, the evidence it must meet, how it would fail, and which other fields bear on it. Mathematics is the base. The same 984 identifiers are served as plain JSON and as SKOS.

How it works

Each claim is placed on four faces: the field whose evidence can establish it, the cell it concerns, the warrant it owes (proof, measurement, a dated record, a stipulation and so on, thirteen types) and the method behind it. The map endpoint runs a subject past every field and reports which ones answered. Tradition-internal authority (W13) is never accepted as evidence for a measurement, a date, a legal duty or the meaning of a word.

Model assist. Placement is done by fixed rules and gives the same answer every time. If the service has a model attached, assist=1 adds a second opinion. It can only choose from a fixed list of field codes, and it never replaces the rule-based answer.

Status

  • Working draft for expert review. The classifier is a keyword and rule engine written alongside the 50-claim pilot, so its pilot scores are a regression floor, not a measure of accuracy.
  • No human placement study has been run. Treat every placement as a suggestion.
  • audit flags are prompts for a reader, not findings about truth.
  • Indigenous knowledge (IK) and all Indigenous placements are provisional until Māori-led review.
  • map counts cue words. A field that does not appear has not been shown to be irrelevant.
