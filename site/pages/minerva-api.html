API

The Worker exposes classify, place, audit, verify, and the field catalog. Paid models stay off unless a flag is set.

POST /v1/verify

Send a text, or a single claim, plus any sources and tool outputs you already hold. The service does not fetch them. With no flag set, the check is rules only. A paid model runs only when VERIFY_MODEL=1, and that flag ships unset. A model label cannot raise a verdict to supported or contradicted.

The verdict is one of: out of scope, contradicted, contested, overstated, supported, unverified. The first match wins. The reply never uses the word true as a verdict.

POST /v1/classify and POST /v1/audit are unchanged. Classify places a claim. Audit returns wording flags for a person to read. Neither returns a verdict.

GET /v1/fields lists the 25 fields. GET /v1/pyramids/FIELD returns the catalog sections. GET /v1/pyramids/FIELD/full returns the full pyramid when R2 or KV is bound, and otherwise a link to the static JSON on this site.
